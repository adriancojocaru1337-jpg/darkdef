# Dark Defense v0.9.0 — Procedural Loot Foundation

## Rezultat

Această versiune livrează primul vertical slice din `v0.9 — Loot & Buildcraft`.
Boss-urile acordă acum echipament procedural, determinist și persistent, fără a
schimba nucleul Tower Defense sau compatibilitatea salvărilor de run v2–v5.

Itemele sunt păstrate în `Loot Cache`. Inventarul navigabil și echiparea nu sunt
simulate în această versiune; ele vor consuma aceleași `ItemInstance` în următorul
slice, astfel încât recompensele câștigate acum nu se pierd.

## Arhitectură implementată

### Content catalog

`js/content/reward-content.js` conține definiții imutabile și data-driven pentru:

- cinci rarități: Common, Uncommon, Rare, Epic și Legendary;
- șase iteme de bază, deblocate progresiv în funcție de stage;
- șapte affixe, cu intervale și restricții de slot;
- tabele de recompense pentru Campaign, Endless și Daily.

Definițiile nu cunosc DOM, Canvas, `localStorage` sau regulile de prezentare.

### RewardGenerator

`js/systems/reward-generator.js` este o funcție pură construită peste `RunRng`.
Primește seed-ul implicit prin RNG, `sourceId`, stage și mode, apoi generează:

- un `bundleId` stabil;
- un `instanceId` stabil;
- item definition, rarity și item level;
- affixe eligibile și valori roll-uite;
- un scor Power reproductibil.

Aceeași sursă produce aceeași recompensă. Un run poate fi reluat și verificat fără
ca rezultatul procedural să se schimbe.

### RewardInbox

`js/systems/reward-inbox.js` gestionează coada persistentă
`profile.rewards.unclaimed`.

- bundle-urile sunt copiate defensiv;
- un `bundleId` deja existent este refuzat;
- itemele rămân în profil între sesiuni;
- sistemul emite `reward:queued` pentru integrarea UI.

Acesta este mecanismul de zero item loss până când Inventory UI este disponibil.

### Profile schema v2

`ProfileStore` migrează profilurile vechi și normalizează:

- `inventory.capacity`;
- `inventory.items`;
- `rewards.pityCounters`;
- `rewards.unclaimed`.

Datele lipsă sau invalide primesc valori sigure, fără a șterge progresul legacy.

### Integrarea în joc

La rezolvarea unui boss:

1. se construiește sursa stabilă din seed, mode, stage și wave;
2. se generează bundle-ul;
3. `RewardInbox` îl persistă înainte de afișare;
4. overlay-ul de reward prezintă rarity, item level, slot, affix și Power;
5. `Run Overview` afișează numărul curent din `Loot Cache`.

Dacă aceeași sursă este procesată din nou, jocul afișează recompensa deja stocată,
dar nu acordă un duplicat.
