# Dark Defense v0.8.2 — Application Architecture

v0.8.2 închide fundația tehnică începută în v0.8. Nucleul de gameplay rămâne neschimbat, dar starea run-ului și comunicația cu backend-ul nu mai sunt răspândite prin cod.

## RunStateMachine

Noul modul `js/core/run-state-machine.js` definește fazele:

- `idle`
- `ready`
- `wave`
- `paused`
- `reward`
- `transition`
- `game_over`

Evenimentele valide sunt explicite: start run, start wave, pause, resume, wave cleared, reward opened, transition started, ready, game over, restore și return to menu.

O tranziție invalidă este respinsă fără mutarea stării. Fiecare tranziție acceptată:

- crește `revision`;
- reține motivul;
- emite `run:transition` prin Event Bus;
- produce un snapshot serializabil.

Integrarea păstrează temporar variabilele legacy `waveActive` și `isPaused` pentru renderer, dar deciziile majore sunt validate de mașina de stare. Acest bridge permite extragerea graduală a monolitului fără rescriere riscantă.

## Run save v5

Save-ul include acum:

```js
runFlow: {
  phase,
  previousPhase,
  mode,
  revision
}
```

Resume intră întotdeauna în faza sigură `ready`; luptele și tranzițiile nu sunt restaurate la jumătate.

Sunt acceptate în continuare versiunile v2, v3 și v4. Dacă `runFlow` lipsește, acesta este reconstruit din `mode` și `daily`.

## ApiClient

`js/core/api-client.js` este singurul punct de acces la Netlify Functions din `game.js`.

Contractul comun include:

- `get(endpoint, options)`;
- `post(endpoint, body, options)`;
- JSON automat;
- query parameters;
- `credentials` și `cache`;
- timeout implicit de 10 secunde;
- anulare prin `AbortSignal`;
- `sendBeacon` pentru salvarea meta la închiderea paginii.

`ApiError` expune:

- `status`;
- `code`;
- `details`;
- `retryable`;
- cauza originală pentru erorile de rețea.

Sunt centralizate session lookup, Ley meta sync, leaderboard load, start-run token, score submission și logout. `game.js` nu mai conține apeluri directe `fetch`.
